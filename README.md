## 👨‍💻 Sobre mí

Soy **Caleb**, ingeniero de software enfocado en **sistemas, rendimiento y backend**. Diseño y construyo software donde la eficiencia, la seguridad de memoria y la mantenibilidad importan: desde utilidades CLI hasta APIs y arquitecturas web escalables.
